# 天猛星 M0G3507 PCB 引脚连接说明

本文档按当前嘉立创EDA工程 `天猛星 / PCB1` 的 PCB 源数据整理。表中的网络名以当前 PCB `PAD_NET` 读取结果为准，不是早期规划。

## 当前模块连接总览

| 模块/位号 | 当前用途 | 实际使用的主控网络 | 说明 |
|---|---|---|---|
| `H1` | 陀螺仪/姿态模块串口 | `A08(UART1_TX)`、`A09(UART1_RX)`、`3V3`、`GND` | MCU TX 接模块 RX，MCU RX 接模块 TX。 |
| `H2` | 电机驱动板串口 | `B02(UART3_TX)`、`B03(UART3_RX)`、`3V3`、`GND` | 只给串口和逻辑参考用，电机动力电源不要从这里取。 |
| `OLED1` | OLED 屏幕 | `A29(I2C1_SCL)`、`A30(I2C1_SDA)`、`3V3`、`GND` | OLED 走 I2C1，供电为 3.3V。 |
| `灰度/循迹接口` | 感为无 MCU 灰度模块 | `A15`、`A14`、`A13`、`A27`、`3V3`、`GND` | 采用厂家 ADC 地址读取方案：`AD0/AD1/AD2 + OUT`。 |
| `K1按键` | 按键 1 | `A07(K1)`、`GND` | 按下为低电平，固件启用内部上拉。 |
| `K2按键` | 按键 2 | `B10(K2)`、`GND` | 按下为低电平。 |
| `K3按键` | 按键 3 | `B11(K3)`、`GND` | 按下为低电平。 |
| `K4按键` | 按键 4 | `B14(K3)`、`GND` | 实际网络接的是 `B14`，但网络名仍写成 `K3`，建议改名为 `B14(K4)`。 |
| `CN3` | 电源输入端子 | `VIN_RAW`、`GND` | 外部电源输入入口。 |
| `D1` | 输入保护二极管 | `VIN_RAW`、`VIN_PROT` | 输入保护链路：`VIN_RAW -> D1 -> VIN_PROT`。 |
| `S1` | 电源开关 | `VIN_PROT`、`VCC_IN` | 开关后电源进入降压模块。 |
| `U3` | AP63205 降压芯片 | `VCC_IN`、`5V`、`SW`、`BST`、`EN`、`GND` | 生成板上 `5V` 电源网。 |

### 灰度/循迹模块接口

| 灰度模块引脚 | M0G3507 网络 | 类型 | 说明 |
|---|---|---|---|
| `VCC` | `3V3` | 电源 | 建议按 3.3V 逻辑供电，避免模拟输出超过 MCU ADC 输入范围。 |
| `GND` | `GND` | 电源地 | 必须和 M0G3507 共地。 |
| `AD0` | `A15 / PA15` | GPIO 输出 | 地址选择位 0，按厂家例程原始引脚连接。 |
| `AD1` | `A14 / PA14` | GPIO 输出 | 地址选择位 1，按厂家例程原始引脚连接。 |
| `AD2` | `A13 / PA13` | GPIO 输出 | 地址选择位 2，按厂家例程原始引脚连接。 |
| `OUT` | `A27 / PA27 / A0_0` | ADC 输入 | 灰度模块模拟输出，接 ADC0 模拟输入 `A0_0`；不要写成 `ADC27`。 |

> 这套接法是 `AD0/AD1/AD2 + OUT` 的模拟地址读取方案，不是 `CLK + DAT` 两线串行方案。`AD0~AD2` 负责选择 8 路灰度通道，`OUT` 输出被选中通道的模拟值。

## 布线和使用注意事项

1. 串口保持交叉连接：MCU `TX` 接模块 `RXD`，MCU `RX` 接模块 `TXD`。
2. 电机驱动板必须和 M0G3507 共地；电机动力电源不要从 M0G3507 或 H2 的 `3V3` 取。
3. `A29/A30` 已用于 OLED I2C，后续不要再分配给按键或串口。
4. `A08/A09` 已用于陀螺仪 UART，`B02/B03` 已用于电机 UART。
5. 灰度模块 `OUT` 是模拟信号，走线尽量短，远离 AP63205 的 `SW` 节点、电感和电机大电流线。
6. 灰度模块 `AD0/AD1/AD2` 是普通 GPIO 地址线，可以按厂家例程使用 `A15/A14/A13`，固件 SysConfig 需和原理图保持一致。
7. 按键线是低速信号，可以走细线，但尽量不要贴着电源开关节点 `SW` 或电机大电流线。
8. `DIO/CLK/RST/CHIP` 属于下载、复位或启动相关信号，除非明确需要调试接口，否则不要拿去接外设。
