# 电机通道识别模式设计

## 目标

在不知道电机驱动板 A/B/C/D 哪两个通道接到车轮的情况下，先做一个低速、可停止的通道识别模式。用户通过 K1~K4 逐路点动电机，观察实际转动的车轮和方向，再把识别结果用于后续陀螺仪直线闭环。

## 范围

| 项目 | 决策 |
|---|---|
| 当前要做 | 按键点动识别电机通道 |
| 当前不做 | 陀螺仪走直线闭环、循迹引脚切换、SysConfig 修改 |
| 当前板子 | 第一版循迹模块未改引脚的板子 |
| 使用外设 | UART3 电机驱动板、K1~K4 按键 |

## 交互方式

| 按键 | 点动通道 | 行为 |
|---|---|---|
| K1 | 电机 A，索引 0 | 只给 A 通道发送低速正转，其余通道 0 |
| K2 | 电机 B，索引 1 | 只给 B 通道发送低速正转，其余通道 0 |
| K3 | 电机 C，索引 2 | 只给 C 通道发送低速正转，其余通道 0 |
| K4 | 电机 D，索引 3 | 只给 D 通道发送低速正转，其余通道 0 |
| 松开全部按键 | 无 | 四路速度全部 0 |
| 多个按键同时按下 | 无 | 四路速度全部 0，避免误判 |

## 安全策略

| 风险 | 处理 |
|---|---|
| 放在地上时突然移动 | 点动速度限制为低速，建议架空车轮测试 |
| 多键误触导致通道混乱 | 多键按下时直接停机 |
| 重复发送占用 UART3 | 只有目标通道变化时才重新发速度帧 |
| 不知道是否已进入闭环 | 电机应用初始化后发送一次闭环命令，失败不阻塞后续任务 |

## 软件结构

| 文件 | 变更 |
|---|---|
| `User/App/motor_app.c` | 在电机任务中加入点动状态机，复用 `Key_AppGetStableMask()` 和 `Motor_AppSetSpeed()` |
| `tests/motor_app_test.c` | 增加主机测试，验证 K1~K4 单键点动、多键停机、松开停机 |

## 后续直线闭环衔接

完成识别后，需要记录：

| 参数 | 示例 |
|---|---|
| 左轮通道 | A/B/C/D 中的一个 |
| 右轮通道 | A/B/C/D 中的一个 |
| 左轮前进符号 | `+` 或 `-` |
| 右轮前进符号 | `+` 或 `-` |

确认这四项后，再新增陀螺仪直线控制任务：上电归零 yaw，按当前 yaw 偏差修正左右轮速度。
